# Security

GridNode injects into a game process and loads other people's DLLs as mods: only run mods you trust.

To report a vulnerability in GridNode (for example the loader, the mod loader, the package tools, or a way for a mod
file to run code other than by being loaded as a mod), open a private security advisory on the GitHub repository,
or contact the maintainer privately, before posting it publicly. Include the version, what you did and what happened.

GridNode is for the single-player PC game. Reports about cheating in online play are not security issues here:
see [docs/online.md](docs/online.md).
