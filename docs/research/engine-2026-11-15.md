# Engine research of 2026-11-15 (blocks A-Z), checked 2026-11-20

Twenty-five answers (blocks A to Z, no K) from another agent, written to `scratch\unverified\` on the user's PC,
checked in Ghidra against `MirrorsEdgeCatalyst_dump_SCY.exe` on 2026-11-20 with three inline scripts: 254 address
claims (function starts, the instruction at an address, call targets) and 17 vtables slot by slot, then a decompile
of every function GridNode now calls or depends on. What was taken is in `db/annotations/` (source `ghidra,
research`); what was used, and how, is in [progress.md](../progress.md).

## Per block

- **A, update passes.** `fb_GameWorld_update` runs passes 0 and 1, the post-updates run 6 and 8, the client frame 5,
  3 and 2, the client world tick 4 (only from `clientWorldFrameTick`); nothing runs pass 7. An updater's `pre`
  (vtable +0x08) returns a value handed to its `post` (+0x10). `EntityUpdater_ctor(self, realm, pass, name,
  priority)` links into the realm list and the pass manager; the inverse of the second link is not found, so
  GridNode does not make updaters of its own yet.
- **B, entity flags.** +0x18: 0x400 queued for destroy, 0x2000000 destroy entered, 0x800000 in the world, 0x10 in
  the class's world list. `Entity_requestDestroy` asks the owner (`EntityOwner_removeEntity`: deinit, unlink, queue);
  `GameWorld_drainDestroyQueue` frees them in each `Level_update`.
- **C, EntityBus.** Bus +0x58's low 25 bits are `(id + 0x1ffff80)`; the peer array (+0x40 of a full bus) is
  parallel to the data key table, last registered wins. `EntityBusPeer_sendEvent` queues to the realm's queue when
  called from another thread; `EntityBusPeer_queueEvent` keeps a plain EntityEvent by id and clones anything else.
- **D, replication.** Entry points checked (`ClientSpawnEntity_createFromNetwork`, `NetState_setDirty`); the rest is
  MECMP's concern.
- **E, data containers.** Refcount `u16` at +0x08 (LOCK INC to take one, `DataContainer_release` to drop it);
  `RuntimeProperty_assignValue` takes and drops references itself for object values.
- **F, allocators.** `Arena_allocFromMember` caches the resolved arena; the page-table free 0x142a3a9e0 traps
  (INT3) on memory no arena owns.
- **G, spawners.** `createCharacter`'s early returns, the delay +0xf0, the state byte +0x108 (0x8: a spawn is
  wanted), the counter +0xf4; the spawner updater is 0x142548128.
- **H / I, replays and recordings.** Header and keyframe layout read in the decompiler (`Recording_Version` in
  `replay.yaml`); `tools/replay/` reads and writes them.
- **J, looks.** `+0x334` (ghost projection shader) and `+0x335` on a PamClientCharacterEntity are read every frame.
- **L, players.** Functions checked; nothing new used.
- **M, messages.** The pump frees a queued message with its deleting destructor after all listeners ran; a message
  type's deleting destructor frees through the page table.
- **N, properties.** The change flag passed to listeners is only bit 0 (first write). Writes are not thread safe:
  GridNode keeps writing on the realm thread.
- **O, physics.** A body queued for destroy stays in the Havok world until the step; `+0xb88[id] & 0x10` marks it.
- **P, camera.** `ClientCameraViewManager_setOverride` (+0x40 transform, +0x80 FOV, +0x84 on), cleared every frame by
  postSimUpdate; the `+0x1b90` list's slot 1 gives an FOV.
- **Q, pause.** `UIPauseController_request(controller, on, full)`; with `full` 0 it pauses only when the view's
  timescale is ~0.
- **R, settings and console.** Matches what `settings.cpp` already does.
- **S, streaming.** Functions checked; zone holds left for the layout editor.
- **T, reflection.** Class id ranges are the game's own subclass test.
- **U, ANT.** A pose provider registered with 0x142fcef00 can feed an animatable's bones (not used yet).
- **V, audio.** GridNode's mixer detour comes out through the patch removal, which pauses every thread first.
- **W, time of day.** `TimeOfDayClockUpdaters[1] +0x28` is the server clock; `+0xf8` holds it, `+0x30` is the time,
  `+0xec` the rate scale.
- **X, threads.** With `Server_runsInlineCheck` true, the server tick can run on a job worker while the client ticks.
- **Y, debug renderer.** A command's flags byte comes from `**(recorder + 0x10)`: 0x4 depth test, 0x8 depth write.
- **Z, small checks.** The localizer's first use is not thread safe.
